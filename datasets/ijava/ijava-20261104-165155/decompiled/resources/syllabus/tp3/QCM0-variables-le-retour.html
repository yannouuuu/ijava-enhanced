Ces trois notions sont cruciales pour stocker et manipuler des données, ce qui est la base permettant ensuite de les traiter automatiquement.

La première semaine, nous avions débuté par la définition de données avant de les traiter de manière différenciée en deuxième semaine grâce à la notion d'alternative et de multiples fois avec les répétitions cette semaine.

Vérifions quand même que nous sommes bien au clair sur ces trois notions fondamentales ;)

::: question Qu'est-ce qu'une valeur ?

  • [ ] Une valeur est une donnée binaire

    Dans l'absolu oui, mais en cours de programmation, on ne descendra pas à ce niveau de représentation des informations.

  • [ ] Une valeur est une information importante à mémoriser

    Ce n'est pas faux, mais on est ici sur la définition d'une valeur et pas son usage.

  • [x] Une valeur est une donnée élémentaire (non décomposable).

    Exactement ! Cela peut être un nombre, un texte, une image, mais pas un tableau ou une autre structure de donnée qui contient plusieurs données.

  • [ ] Je n'en ai aucune idée ...

    Il est très important de relire le cours avec les TD et les TP ! :::

::: question Qu'est-ce qu'un type ?

  • [ ] Un type définit un ensemble de valeurs possibles.

    Presque, le type définit aussi les opérations que l'on peut réaliser sur ces valeurs.

  • [x] Un type définit la nature d'une donnée : son espace de valeurs et les opérations applicables dessus.

    Bravo, c'est exactement cela :)

  • [ ] Un type c'est ce que l'on met avant le nom d'une variable.

    Pas faux, mais cela n'explique pas ce qu'est un type ...

  • [ ] Un type c'est un nombre, une chaîne de caractères, une image, un son ...

    Certes, ce sont des exemples mais ne définit pas précisément ce qu'est un type. :::

::: question Qu'est-ce qu'une variable ?

  • [ ] Une variable stocke une donnée en mémoire et possède un nom.

    Certes, mais ce n'est pas assez précis.

  • [x] Une variable associe trois éléments : un type, un identifiant et une valeur.

    Effectivement, deux éléments cruciaux pour la nature (type) et surtout un nommage explicite (identifiant) de ce que représente la donnée et une valeur pouvant être précisé à la déclaration ou plus tard dans le programme.

  • [ ] Une variable mémorise une donnée qui évolue durant l'exécution du programme.

    Certes, mais on souhaite une définition plus précise.

  • [ ] Une variable est une donnée qui varie de manière probable.

    Généralement, c'est de manière certaine : on préfère le déterminisme en informatique (sauf avec les LLM :p) :::
