# Le plus petit nombre

Écrire le programme `PlusPetitNombre` qui affiche le plus petit nombre parmi les deux saisis au clacier par l’utilisateur. 

Voici deux exemples d’exécutions attendues :
```bash
Entrez deux nombres :
12
7
Le plus petit est 7
```

```bash
Entrez deux nombres :
-1
-1
Le plus petit est -1
```
