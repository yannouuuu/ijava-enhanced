# Écho sans echo

Concevez le programme `Echo` qui prend une chaîne de caractères `phrase` et un nombre `n` et affiche `n` fois la chaîne `phrase` avec un retour à la ligne entre chaque phrase. 

Voici deux exemples d’exécutions attendues.
```bash
~/ijava2/tp2> ijava execute Echo
Chaîne à répéter : Hello
Nombre de fois : 2
Hello
Hello
~/ijava2/tp2> ijava execute Echo
Chaîne à répéter : Joyeux anniversaire
Nombre de fois : 3
Joyeux anniversaire
Joyeux anniversaire
Joyeux anniversaire
```

N'oubliez pas de tester votre programme (ìjava test Echo) avant de passer à la suite !
