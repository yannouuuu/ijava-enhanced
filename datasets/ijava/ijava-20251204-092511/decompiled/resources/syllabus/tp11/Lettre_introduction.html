Création du type `Lettre``

tp11 / Lettre_introduction.java

Créez le nouveau type Lettre dans le fichier Lettre.java afin qu'il contienne un champs pour stocker le caractere et un autre pour déterminer si ce caractère est decouvert ou pas.

N'oubliez pas de compiler afin de vérifier que tout est syntaxiquement correct !

::: question Avez-vous bien un fichier Lettre.class dans votre répertoire ?

  • [x] Oui.

    Ok, c'est que la création du type s'est correctement déroulé et il est maintenant utilisable dans d'autres programmes.

  • [ ] Non.

    Vérifiez bien que le nom du type est exatement le même que le nom du fichier (avant l'extension .java) et qu'il n'y a pas d'erreur de compilation. :::
