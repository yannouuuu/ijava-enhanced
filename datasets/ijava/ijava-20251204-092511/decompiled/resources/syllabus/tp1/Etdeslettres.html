Instructions

De manière similaire à l'exercice précédent, on souhaite désormais créer un programme LettreAuHasard qui affiche une lettre au hasard parmi les majuscules (par exemple pour jouer au mot le plus long en l'appelant autant de fois que de lettres souhaitées). \begin{correction} On peut les amener à un raisonnement du même genre que le précédent ici. Attention, là encore, des étudiants seront tentés d'aller chercher le code ASCII pour écrire leur programme avec des valeurs entières en dur.

void algorithm() {
int numLettre = (int) 'A' + (int) (26 * random()); 
println( (char) numLettre );
}

\end{correction}
