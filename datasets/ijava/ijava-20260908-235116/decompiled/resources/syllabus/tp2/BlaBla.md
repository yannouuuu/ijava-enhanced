# Blabla

On veut repérer les mots constitués d’une suite de lettres qui se répète deux fois comme `tintin`, `rentrent` ou parce que l'on est à Lille, `quinquin`.

Complétez le squelette du programme `Blabla.java` pour réaliser cette fonctionnalité.

Testez ensuite manuellement votre programme avec le mot `couscous` (on devrait avoir `true`) puis `zigzag` (`false`).

Terminez l'exercice avec l'habituelle commande `test` d'ijava.
