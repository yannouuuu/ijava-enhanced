# Bases sur la notion de fonction


::: question
**Qu'est-ce qu'une fonction en ijava ?**

- [ ] Un bloc de code qui s'exécute lorsque le programme est lancé.
  > Non, c'est la classe principale qui s'exécute en premier lieu.
- [x] Une méthode qui effectue une tâche spécifique et peut retourner une valeur.
  > Effectivement, c'est la définition d'une fonction en ijava.
- [ ] Une instruction qui permet de déclarer des variables.
  > Non, la déclaration de variables se fait avec un type comme int, String, etc.
- [ ] Un opérateur pour effectuer des calculs.
  > Ce sont les opérateurs qui effectuent des calculs, pas les fonctions.
:::

::: question
**Quel est le mot-clé pour déclarer une fonction en ijava ?**

- [ ] function
  > Non, "function" n'est pas un mot-clé en ijava.
- [ ] def
  > Non, "def" est utilisé en Python.
- [ ] method
  > Non, le mot-clé "method" n'existe pas non plus en ijava.
- [x] il ne faut pas de mot-clé !
  > Exact !
:::

::: question
**Que signifie le mot-clé void dans la déclaration d'une fonction ?**

- [x] La fonction ne retourne pas de valeur.
  > Effectivement, "void" indique qu'aucune valeur n'est retournée.
- [ ] La fonction retourne un entier.
  > Non, "void" signifie qu'il n'y a pas de retour, c'est int pour un entier.
- [ ] La fonction retourne une chaîne de caractères.
  > Non, cela doit être spécifié par un type de retour, comme String.
- [ ] La fonction ne fait rien.
  > Non, c'est juste qu'elle ne retourne aucun résultat.
:::

::: question
**Comment appelle-t-on une fonction ?**

- [x] En utilisant le nom de la fonction suivi de parenthèses.
  > Effectivement, c'est la bonne syntaxe pour appeler une fonction.
- [ ] En utilisant le mot-clé "call".
  > Non, "call" n'est pas utilisé en ijava pour appeler des fonctions.
- [ ] En déclarant la fonction à nouveau.
  > Non, il n'est pas nécessaire (ni possible !) de redéclarer une fonction pour l'appeler.
- [ ] En utilisant le mot-clé "invoke".
  > Non, "invoke" n'est pas un mot-clé en ijava.
:::

::: question
**Quelle est la signification des paramètres d'une fonction ?**

- [ ] Les valeurs qu'une fonction retourne.
  > Non, ce sont les valeurs que la fonction reçoit en entrée.
- [x] Les entrées que la fonction peut accepter.
  > Correct, ce sont les variables placées dans les parenthèses de la fonction.
- [ ] Les types de données que la fonction peut retourner.
  > Non, les types de données sont définis par le type de retour de la fonction.
- [ ] Les valeurs constantes définies dans la fonction.
  > Non, ce sont des variables qui peuvent être utilisées à l'intérieur de la fonction.
:::
