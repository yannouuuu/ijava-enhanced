# Calcul du minimum, maximum et de la moyenne

Tout est dans le titre ou presque !

On souhaite un programme `MinMaxMoyenne` saisissant une suite d'entiers terminée par la valeur `0` (qui est donc exclue des calculs) et qui affiche la valeur minimale, maximale et la moyenne de toutes les valeurs saisies.

```bash
~ijava2/tp4bis> ijava execute MinMaxMoyenne
-2
2
-5
4
18
-9
-7
7
0
Minimum = -5 / Maximum = 18 / Moyenne = 1
```

Et si jamais l'on a un usager un peu taquin ...

```bash
~ijava2/tp4bis> ijava execute MinMaxMoyenne
0
Minimum = 0 / Maximum = 0 / Moyenne = ?
```
