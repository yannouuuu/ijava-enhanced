# Extraire le suffixe d'une chaîne de caractères

On vous demande de concevoir un programme `Suffixe` qui affiche les `nbLettres` derniers caractères d'une chaîne de caractères saisie au clavier.

Voici un premier exemple d'exécution :
```bash
Entrez une chaîne de caractère : Bonjour
Nombre de lettres de fin souhaitées : 4
Résultat : jour
```

Et un second :
```bash
Entrez une chaîne de caractère : Au revoir
Nombre de lettres de fin souhaitées : 6
Résultat : revoir
```

Et finalement, si l'on est dans une situation incohérente, voici ce qu'il faut produire :
```bash
Entrez une chaîne de caractère : Bonjour
Nombre de lettres de fin souhaitées : 10
Erreur, pas assez de caractères !
```

Une fois satisfait par vos tests réalisés manuellement, n'oubliez pas le `test` d'ijava !
