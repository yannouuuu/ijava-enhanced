## Un problème classique ...

Le but de cet exercice est d'écrire un algorithme qui échange le contenu de deux variables de type chaîne `chaine1` et `chaine2`. Ainsi, si l'on dispose de deux variables `chaine1` et `chaine2`, à la fin de l'algorithme, le contenu de la variable `chaine1` doit être celui contenu initialement par `chaine2` et réciproquement.

```java
class Permutation extends Program {
    void algorithm() {
        String chaine1 = readString();
        String chaine2 = readString;
        // A COMPLÉTER par le(s) instruction(s) permutant les valeurs des deux 
        // variables chaine1 et chaine2. Le programme doit pouvoir fonctionner 
        // quelque soit le type des varialbles (entier, caractères, booléens ...)
        println("Après échange, chaine1 = " + chaine1 + " et chaine2 = " + chaine2);
    }
}
```
