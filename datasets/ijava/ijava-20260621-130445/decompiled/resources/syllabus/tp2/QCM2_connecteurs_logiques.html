Connecteurs logiques en ijava

tp2 / QCM2_connecteurs_logiques.java

::: question En ijava, comment s'exprime la négation logique ?

  • [x] !

    Parfait : bien joué !

  • [ ] !!

    Incorrect : un seul point d'exclamation est suffisant ;)

  • [ ] not

    Faux : nous ne sommes pas en python ...

  • [ ] non

    Incorrect : en (i)java tous les mots-clés du langage sont en anglais ! :::

::: question En ijava, comment s'exprime le ET logique ?

  • [ ] et

    Incorrect : en (i)java tous les mots-clés du langage sont en anglais !

  • [ ] and

    Faux : nous ne sommes pas en python ...

  • [x] &&

    Parfait : bien joué !

  • [ ] AND

    Incorrect : un mot tout en majuscules fait plutôt référence à une constante. :::

::: question En ijava, comment s'exprime le OU logique ?

  • [ ] ou

    Incorrect : en (i)java tous les mots-clés du langage sont en anglais !

  • [x] ||

    Parfait : bien joué !

  • [ ] or

    Faux : nous ne sommes pas en python ...

  • [ ] ^

    Incorrect : cet opérateur est utilisé pour un autre connecteur ... :::

::: question La chaîne mot1 est plus grande que la chaîne mot2 s'écrit ... ?

  • [ ] length(mot1>mot2)

    Incorrect : en (i)java tous les mots-clés du langage sont en anglais !

  • [ ] length(mot2) > length(mot1)

    Incorrect : cet opérateur est utilisé pour un autre connecteur ...

  • [x] length(mot1) > length(mot2)

    Faux : nous ne sommes pas en python ...

  • [ ] length(mot1) < length(mot2)

    Parfait : bien joué ! :::

::: question Si la condition (a < b && a < c) est vérifiée, cela veut dire que ...

  • [ ] a est plus petit que b ou c

    Incorrect : en (i)java && correspond au ET logique !

  • [x] a est plus petit

    Parfait : bien joué !

  • [ ] b est plus petit que c

    Faux : b n'est comparé qu'avec a :::
