# Des dés mult-faces !

Modifier le programme `DeMultiface` de manière à ce qu'il demande à l'utilisateur un dé à combien de faces il veut lancer et affiche le résultat. Pour ce faire, on pourra utiliser la fonction `int readInt()` fonctionnant sur le même principe que `char readChar()` vue précédemment mais renvoyant un entier, comme son nom l'indique.

Le programme devra avoir un affichage similaire à cela :
```bash
ijava execute DeMultiface
Combien de faces ? 18
14
```

## Étapes à suivre
-  *complétez le code source avec un éditeur de texte et sauvez bien votre fichier !*
- `ijava compile De.java`
- `ijava execute De`
- `ijava test De`
