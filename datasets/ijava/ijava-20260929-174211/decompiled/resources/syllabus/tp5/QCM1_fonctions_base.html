::: question Qu'est-ce qu'une fonction en ijava ?

  • [ ] Un bloc de code qui s'exécute lorsque le programme est lancé.

    Certes, algorithm est une fonction exécutée automatiquement au lancement, mais là, on souhaite la définition générale d'une fonction, pas un cas particulier ...

  • [x] Un programme réutilisable qui effectue une tâche spécifique et produit souvent une valeur en résultat.

    Effectivement, c'est la définition d'une fonction en ijava (et dans les autres langages !ç.

  • [ ] Une instruction qui permet de déclarer des variables.

    Non, la déclaration de variables se fait avec un type (comme int, String, etc.) suivi d'un identifiant (qui doit signifier quelque chose !).

  • [ ] Un opérateur pour effectuer des calculs.

    Les opérateurs ne sont pas des fonctions, ils ont une syntaxe totalement différente (dans d'autres langages, les opérateurs sont des fonctions comme les autres). :::

::: question Quel est le mot-clé pour déclarer une fonction en ijava ?

  • [ ] function

    Non, "function" n'est pas un mot-clé en (i)java.

  • [ ] def

    Non, "def" est utilisé en Python. Il vous faut oublier Python maintenant ;-)

  • [ ] method

    Non, le mot-clé "method" n'existe pas non plus en (i)java.

  • [x] il ne faut pas de mot-clé !

    Exact ! On donne le type du résultat, le nom de la fonction et la liste de ses paramètres (c'est-à-dire les données nécessaires pour réaliser le calcul souhaité). :::

::: question Que signifie le mot-clé void dans la déclaration d'une fonction ?

  • [x] La fonction ne retourne pas de valeur.

    Effectivement, "void" indique qu'aucune valeur n'est retournée. On parle dans ce cas de procédure.

  • [ ] La fonction retourne un entier.

    Non, "void" signifie qu'il n'y a pas de retour, c'est int pour un entier.

  • [ ] La fonction retourne une chaîne de caractères.

    Non, cela doit être spécifié par un type de retour, comme String.

  • [ ] La fonction ne fait rien.

    Non, c'est juste qu'elle ne retourne aucun résultat (souvent, c'est utilisé pour réaliser des affichages). :::

::: question Comment appelle-t-on une fonction ?

  • [x] En utilisant le nom de la fonction suivi de parenthèses et d'arguments si nécessaire.

    Effectivement, c'est la bonne syntaxe pour appeler une fonction.

  • [ ] En utilisant le mot-clé "call".

    Non, "call" n'existe pas en (i)java.

  • [ ] En déclarant la fonction à nouveau.

    Non, il n'est pas nécessaire (ni possible !) de redéclarer une fonction pour l'appeler.

  • [ ] En utilisant le mot-clé "invoke".

    Non, "invoke" n'est pas un mot-clé en (i)java. :::

::: question Quelle est la signification des paramètres d'une fonction ?

  • [ ] Les valeurs qu'une fonction retourne.

    Non, ce sont les valeurs que la fonction reçoit en entrée.

  • [x] Les entrées dont la fonction a besoin pour réaliser son traitement.

    Correct, ce sont les valeurs placées dans les parenthèses après le nom de la fonction.

  • [ ] Les types de données que la fonction peut retourner.

    Non, les types de données sont définis par le type de retour de la fonction.

  • [ ] Les valeurs constantes définies par la fonction.

    Non, ce sont des variables qui seront utilisées dans la fonction. :::
